# Kafi Sync — Releases

Public release APKs for the **Kafi Sync** Android app (SMS → KafiPay payment sync).

The app checks this repo's **latest release** on launch and offers an in-app update
when a newer version is out. Each release is tagged with its Android `versionCode`
(the plain number, e.g. `9`) and carries the signed `.apk` as an asset.

Source code is kept in a separate private repository.
